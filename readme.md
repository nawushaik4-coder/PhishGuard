# PhishGuard

## Project Overview

PhishGuard is a research-based cybersecurity
application designed to analyze potentially
suspicious URLs.

The application will use URL analysis techniques
to identify warning signs and provide an
explainable risk assessment.

## Objectives

1. Analyze submitted URLs.
2. Identify suspicious URL characteristics.
3. Explain the reasons behind a risk assessment.
4. Store scan history in MySQL.
5. Compare detection techniques through experiments.
6. Present research findings through a dashboard.

## Technology Stack

- Frontend: React and Vite
- Backend: Python and FastAPI
- Database: MySQL
- Data Analysis: pandas
- Machine Learning: scikit-learn
- Version Control: Git

## Research Direction

Explainable phishing URL detection and evaluation
of rule-based and machine-learning approaches.

## Project Status

Initial development.

## Limitations

A low risk score does not guarantee that a URL
is safe. Detection results must be evaluated
using appropriate data and experiments.
